# Deployment checklist

- [ ] Supabase project created
- [ ] `sql/schema.sql` successfully applied
- [ ] Supabase URL + publishable key added to `config.js`
- [ ] First account registered and email confirmed (if enabled)
- [ ] Authorized admin promoted using the SQL command in README
- [ ] Test Nurse account created
- [ ] RLS verified for anonymous, Nurse and Admin users
- [ ] GitHub Pages deployed and Supabase auth redirect URLs configured
- [ ] Synthetic data only during testing
- [ ] Hospital approval, privacy/security review, backup/recovery test and clinical validation completed before real patient data
